**Recommended fix**:

```python
def __exit__(self, exc_type, exc_val, exc_tb) -> bool:
    try:
        if exc_type is not None:
            try:
                self.rollback()
            except Exception:
                logger.exception("rollback failed during __exit__")
        else:
            self.commit()
    finally:
        if self.session:
            self.session.close()
    return False
```

1. `finally` guarantees `session.close()` runs regardless
2. Rollback exceptions are caught and logged, preserving the original exception from the with-body
3. Commit exceptions are allowed to propagate — if there was no prior exception, the caller should see it
