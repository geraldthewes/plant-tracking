# Hermes Domain — Ontology

> External AI agent integration, natural language querying, and care recommendations.

---

## hermes.hermes-agent

- id: hermes.hermes-agent
- status: active
- owner: core-team

An external AI agent accessed via Telegram that provides natural language querying, data analysis, and care recommendations. Communicates with the Plant Tracking System API to fetch and update plant data. Not the same as `plant.plant` — Hermes is the external AI service; Plant is the tracked entity.

**Capabilities:** Query plant data, compare plants, analyze care history, add notes, predictive insights (future).

**Used by:** FastAPI API routes, Telegram integration, ADR-0007.

---

## hermes.care-recommendation

- id: hermes.care-recommendation
- status: active
- owner: core-team

An analysis or suggestion generated by the Hermes Agent based on plant data patterns. Not the same as `care-logging.note-event` — care recommendations are AI-generated suggestions; note events are user-recorded observations.

**Used by:** Hermes Agent responses, Telegram messages.

---

## hermes.pattern-analysis

- id: hermes.pattern-analysis
- status: active
- owner: core-team

Comparative analysis of plant data to identify correlations between care patterns and outcomes. Not the same as `hermes.care-recommendation` — pattern analysis is the diagnostic process; care recommendation is the suggested action.

**Used by:** Hermes Agent queries, API data aggregation.
