# Add support for plant notes and pictures

> **Workflow Status**: Requirements gathered ✓ → Ready for `/create_plan_generic` to research and plan

## Problem Statement & Business Context

**What problem are we solving?**
Users need to attach rich media and observations to their tracked plants — not just structured data, but freeform notes, photos, videos, and audio recordings.

**Why is this important?**
Plant tracking is more valuable when users can document visual progress, care observations, and memories alongside their plants.

**Who needs this?**
End users of the plant tracking app via CLI or web API.

## Reference Implementation (To Research)

**Location**: TBD — identify existing media/attachment patterns in the codebase during planning.

**Aspects to mimic**:
- How existing entities are modeled in the Python package
- How the CLI exposes CRUD operations
- How the FastAPI service handles file uploads and S3 integration
- Any existing S3 configuration or bucket patterns

> Note: Detailed analysis of reference will happen during planning phase

## Requirements & Scope

### Must-Have Features

#### Notes
- Markdown text notes, timestamped, attached to a plant
- Multiple notes per plant (unlimited)
- Full CRUD: create, read (list), update, delete

#### Images
- Images stored in S3, timestamped, attached to a plant
- Optional text label describing the image
- Optional tags
- Multiple images per plant (unlimited)
- Full CRUD: create, read (list), delete

#### Videos
- Videos stored in S3, same pattern as images (label, tags, timestamped)
- Multiple per plant, full CRUD

#### Audio Notes
- Audio files stored in S3, same pattern as images (label, tags, timestamped)
- Multiple per plant, full CRUD

#### Coverage
- All four content types supported across: Python package, CLI, FastAPI web service

### Nice-to-Have Features
- Image thumbnails / previews generated on upload
- Search or filter notes/media by tags

### Out of Scope
- Sharing notes/media with other users
- Bulk operations (create/delete many at once)

## Constraints & Context

**Integration Points**: S3 for media storage

**Preferred Technologies**: Existing Python package, CLI, and FastAPI patterns

**Constraints**:
- Media files stored in S3 (images, video, audio)
- Notes are text-only, stored in the database

## Success Criteria
