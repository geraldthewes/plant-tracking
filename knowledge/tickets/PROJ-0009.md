# Add plant list and show CLI commands

> **Workflow Status**: Requirements gathered ✓ → Ready for `/create_plan_generic`

## Problem Statement & Business Context

The CLI is missing `list-plants` and `show-plant`. You can list seed packets and genera, but not plants — forcing users to know exact plant IDs.

**Why important:** Completes the list/show pattern across all entity types. Enables plant discovery before logging, labeling, etc.

## Reference Implementation

- `list-seed-packets` (line 1099) — table format, service + fallback
- `list-genera` (line 1386) — same table format
- `show-seed-packet` (line 1156) — detailed field display
- Service layer: `plant_service.py` — `list_plants()` → `Iterator[Plant]`, `get_plant()` → `Plant | None`

## Requirements & Scope

### Must-Have
- **`list-plants`** — table output (ID, Variety, Latin Name, Planting Date), iterator pattern via service layer
- **`show-plant <id>`** — all plant fields, service layer + fallbacks
- Iterator pattern: `list_plants()` returns `Iterator[Plant]`, not a collection

### Out of Scope
- `update-plant`, `delete-plant`
- Filtering/sorting
- API/UI endpoints

## Success Criteria
- [ ] Both commands registered, accessible via `--help`
- [ ] `list-plants` table output matches existing list commands
- [ ] `show-plant` displays all Plant domain fields
- [ ] Empty/error cases handled gracefully
- [ ] All existing tests pass, lints pass
